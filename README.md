# Guard Core SaaS - public issue tracker

This repository is the **public issue tracker** for the Guard Core SaaS at [app.guard-core.com](https://app.guard-core.com). No source code lives here.

## When to open an issue

- **Bugs**: something in the SaaS misbehaves. Include the steps to reproduce, what you expected, and what happened.
- **False positives / missed detections** reported by the platform: include the event ID or the detection name.
- **Feature requests**: describe the outcome you need, not the implementation.

## Ground rules

- Search existing issues (open and closed) before opening a new one.
- One report per issue.
- Never post credentials, API keys, tokens, or payload data that is not yours.
- Reports in English, please.

## Security vulnerabilities

Do **not** open a public issue for a security vulnerability. Report it privately through the app's contact channels and we will credit you in the advisories once it is fixed.
